# Контекст ответа в сообщениях

Чтение сообщений и ожидание ответа сохраняют необязательное поле reply_to:

- reply_to_msg_id — сообщение, на которое ответили;
- reply_to_top_id — начало обсуждения, если оно задано;
- quote_text и quote_offset — выделенная отправителем цитата и её смещение;
- reply_to_chat_id — исходный чат при межчатовом ответе.

Если ответ или цитата отсутствуют, reply_to равно null. Метаданные берутся из уже прочитанного сообщения, без дополнительных запросов к другим сообщениям и чатам. Фраза «на это время» без явной цитаты сама по себе не определяет один вариант из списка.
